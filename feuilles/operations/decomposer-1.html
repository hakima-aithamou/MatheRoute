🧮 Additionner et soustraire en décomposant

Feuille 1 · Les dizaines avec les dizaines, les unités avec les unités

34 + 25 = (30 + 20) + (4 + 5) = 50 + 9 = 59.   On additionne les dizaines, puis les unités.

Additionne en décomposant.

34 + 25 = (30 + 20) + (4 + 5) = 50 + 9 = 59
52 + 36 = (50 + 30) + (2 + 6) = 80 + 8 = 88
41 + 27 = (40 + 20) + (1 + 7) = 60 + 8 = 68

Soustrais en décomposant.

68 − 25 = (60 − 20) + (8 − 5) = 40 + 3 = 43
97 − 43 = (90 − 40) + (7 − 3) = 50 + 4 = 54
75 − 31 = (70 − 30) + (5 − 1) = 40 + 4 = 44

Calcule dans ta tête : les dizaines, puis les unités.

23 + 45 = 68
61 + 18 = 79
87 − 34 = 53
59 − 26 = 33
